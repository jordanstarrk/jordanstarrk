### **[mcp-surfaceprint](https://github.com/mcp-surfaceprint/mcp-surfaceprint)** (open source)  
Create a durable record of an MCP server’s declared capability surface and detect when it changes.

An upgrade can add new tools, parameters, resources, prompts, or actions beneath an existing tool name. MCP Surfaceprint makes those changes visible and reviewable before you trust the new version.

- Captures the tools, resources, prompts, and schemas declared by an MCP server
- Produces deterministic snapshots that can be committed and reviewed over time
- Detects structural changes between versions
- Includes a `check` command for CI and upgrade gating
- Published as an open-source CLI on PyPI

MCP Surfaceprint is not a runtime security system and does not prove that a server is safe. It creates durable evidence of the capability surface you reviewed, so later changes can be detected and assessed. [Read the deeper problem framing and experiments](https://docs.google.com/document/d/1Nn2unJAq36TEob8aPJ74TXoEFBi-WZ727LLl5WnMZ54/edit?tab=t.0)
